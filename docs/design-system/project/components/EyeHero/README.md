ส่วนเปิดหน้าแรกที่ตัว O ใน Grow เป็นดวงตา และขยายเป็นภาพเต็มจอเมื่อเลื่อน

- **ผู้ใช้ต้องส่ง** `lines`, `chips`, `eyeImage`, `subtitle`, `lead`, `actions`, `reveal`
- H1 ต้องแสดงทันที ไม่หน่วง
- ใช้หน้าละครั้งและเฉพาะหน้าแรก
- จอเล็กซ่อนภาพในบรรทัด เมื่อลดการเคลื่อนไหวจะไม่ตรึงหน้าจอ
- ใช้ `clip-path: circle()` บนภาพเต็มจอเพื่อให้ภาพคมตลอดการขยาย
