# แผน 1: ตำแหน่งใหม่และโครงบริการ

## สิ่งที่เปลี่ยน

| เรื่อง | เดิม | ใหม่ |
| --- | --- | --- |
| เราคือใคร | Software house รับทำเว็บ เริ่ม ฿3,900 | ทีมเดียวที่ทำได้ตั้งแต่ระบบ หน้างาน จนถึงการตลาด |
| จุดขาย | เร็ว ถูก มี AI ช่วย | ความครบ การลงมือจริง และเครื่องมือที่เป็นของแบรนด์ |
| ลูกค้าหลัก | SME ที่อยากได้เว็บแรก | แบรนด์ ผู้จัดงาน องค์กรและภาครัฐ |
| ราคา | แสดงบนเว็บ | ไม่แสดงบนเว็บ ทำใบเสนอราคาหลังคุย |
| ภาพลักษณ์ | น้ำเงินและทองเต็มหน้า | ขาว โปร่ง สร้างสรรค์ สีแบรนด์เฉพาะจุดสำคัญ |

## ข้อความหลัก (ร่าง)

- สโลแกน: **Brand Experience, Engineered.** / **ประสบการณ์แบรนด์ ที่สร้างได้จริง**
- คำหลัก: **Build. Activate. Grow.**
- ภาษาไทย: **สร้างระบบ สร้างกระแส สร้างลูกค้า**
- ประโยคบริษัท: ทีมเดียว ตั้งแต่ระบบถึงหน้างาน

## 3 เสา 6 บริการ

| เสา | บริการ | สิ่งที่ส่งมอบ |
| --- | --- | --- |
| Build | เว็บไซต์และซอฟต์แวร์ | เว็บองค์กร เว็บแอป โมบายแอป ระบบองค์กร |
| Activate | Event Interactive | เกมและประสบการณ์บน Kiosk จอทัชสกรีน |
| Activate | KOL และ Influencer | คัดเลือก วางแผน และทำ creative ให้แคมเปญ |
| Activate | Event Content และรีวิว | ไปถ่ายทำ ตัดต่อ หรือรีวิวโดยทีมงาน |
| Grow | Digital Marketing | วางแผน ดูแลโซเชียลและเพจ ยิงแอด หากลุ่มเป้าหมาย หาลูกค้าใหม่ |
| Grow | Social Listening และรายงาน | ทำร่วมกับพาร์ตเนอร์ ออกรายงานให้แบรนด์ |

เบื้องหลังทุกบริการคือซอฟต์แวร์ที่เราสร้าง และเปิดให้ทีมที่อยากใช้ AI เชื่อมต่อเข้ามาดูและถามได้ผ่าน MCP

## กติกาความน่าเชื่อถือ

- Social Listening ต้องติดป้าย "จัดทำร่วมกับพาร์ตเนอร์" ทุกครั้ง
- ผลงานเดิมเป็นงานระบบทั้งหมด ก่อนเปิดเว็บใหม่ต้องมีเคสจริงของ Activate และ Grow อย่างน้อยเสาละ 1 เคส
- ภาพคอนเซปต์ AI ใช้สร้างบรรยากาศเท่านั้น

## อ้างอิงจาก AnyMind

ยืมวิธีจัดโครงสร้าง แต่หน้าตาเป็นของ ODH

| แนวคิดของ AnyMind | ของ ODH |
| --- | --- |
| พื้นขาว ตัวอักษรใหญ่ เรียบแบบบริษัทใหญ่ | ทั้งระบบ |
| ภาพแทรกใน Hero | ภาพแทรกในบรรทัดของ `EyeHero` |
| แยกบริการตามกลุ่ม | `ThreeActs` |
| รายการข่าวและบริการ | `NewsList`, `ServiceIndex` |
| แถบตัวเลข | `StatRow` ที่บังคับมีแหล่งข้อมูล |
