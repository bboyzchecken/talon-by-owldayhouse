# งานกับสำนักบัญชี

สถานะ: ทำแล้ว 17 พ.ย. 2026 · หน้า `/docs/accounting` (แอดมิน)

## หลัก

- **สำนักบัญชีเป็นคนออก 50 ทวิ และยื่นภาษีเท่านั้น** ระบบนี้ไม่ออก 50 ทวิ และไม่ยื่นภาษีเอง
- **สำนักบัญชีไม่เข้าระบบ** คุยกันในกลุ่ม LINE ตามเดิม ระบบเตรียมข้อความให้คัดลอกไปวาง และจดว่าแต่ละเรื่องไปถึงไหน
- ไม่มีอีเมล (ตาม CLAUDE.md) ไม่มีการส่งอัตโนมัติ ถ้าภายหลังมี LINE Official Account ค่อยต่อ Messaging API ให้โพสต์เข้ากลุ่มเอง

## 50 ทวิ ที่เราหักผู้รับเงิน

ทุกครั้งที่บันทึกจ่ายเงินผู้ขายพร้อมหัก ณ ที่จ่าย รายการเข้าคิวนี้เอง

| ขั้น | ในระบบ | ทำอะไร |
| --- | --- | --- |
| 1 ต้องขอ | `wht_cert_status = pending`, `wht_requested_at` ว่าง | เลือกรายการ → คัดลอกข้อความ → วางใน LINE → กด "ส่งใน LINE แล้ว" |
| 2 รอบัญชีส่งกลับ | มี `wht_requested_at` แต่ยังไม่มีไฟล์ `payment_wht` | บัญชีส่งไฟล์มาใน LINE → แนบที่แถวนั้น · มีข้อความทวงถามให้คัดลอก |
| 3 ส่งต่อผู้รับเงิน | มีไฟล์แล้ว สถานะยัง `pending` | ส่งไฟล์ให้ผู้รับเงิน → กด "ส่งให้ผู้รับเงินแล้ว" (`done`) |

ข้อความขอ 50 ทวิ มีทุกอย่างที่บัญชีใช้ออกหนังสือ: ชื่อ เลขผู้เสียภาษี สาขา ที่อยู่ของผู้รับเงิน
(จากข้อมูลที่ล็อกไว้ตอนออกรายจ่าย) วันที่จ่าย แบบ ภ.ง.ด.3/53 ประเภทเงินได้ (รายละเอียดบรรทัดที่หัก)
จำนวนเงินที่จ่ายก่อน VAT อัตรา ภาษีที่หัก เลขรายจ่ายและเลขใบกำกับของผู้ขาย
ถ้าเลขผู้เสียภาษีหรือที่อยู่ว่าง หน้าจอเตือนก่อนส่ง · ขอแล้วลงประวัติบนรายจ่าย (`wht_requested`)

## ภาษีรายเดือน

สำนักบัญชียื่น ภ.พ.30 และ ภ.ง.ด.3/53 แล้วส่ง QR e-tax มาใน LINE เราจ่ายเอง

| ขั้น | ในระบบ (`tax_filings`) | ทำอะไร |
| --- | --- | --- |
| 1 ส่งข้อมูลให้บัญชี | `sent_at` | คัดลอกข้อความสรุปยอดของงวด + ดาวน์โหลด zip ของเดือน → วางใน LINE → "ส่งใน LINE แล้ว" (ทุกแบบของงวดพร้อมกัน) |
| 2 ได้ QR จากบัญชี | `due_amount`, `due_set_at` | ใส่ยอดตาม QR ระบบเทียบกับยอดของเรา ถ้าไม่ตรงขึ้นเตือนให้ถามบัญชีก่อนจ่าย |
| 3 จ่ายแล้ว | `status = filed` | ที่หน้าภาษีรายเดือน แนบสลิป/ใบเสร็จ ยอดที่จ่ายตั้งต้นเป็นยอดตาม QR (ล็อกยอดเหมือนเดิม) |

ทุกขั้นลงประวัติของงวด (`document_events.tax_filing_id`: `tax_sent`, `tax_due`, `tax_filed`)
งวดที่จ่ายแล้วทำขั้น 1–2 ซ้ำไม่ได้ (409) ต้องเปิดแก้ไขงวดก่อน
หน้าแสดงทุกงวดใน 12 เดือนที่ยังไม่จบ และงวดล่าสุดเสมอ

## API

| Method | Path | ทำอะไร |
| --- | --- | --- |
| `GET` | `/api/docs/accounting` | คิว 50 ทวิ ทั้ง 3 ขั้น พร้อมข้อมูลผู้รับเงิน และงวดภาษีที่ยังไม่จบ |
| `POST` | `/api/docs/accounting/wht-requested` | `{payment_ids}` บันทึกว่าขอแล้ว |
| `POST` | `/api/docs/tax/filings/:fid/sent` | ส่งข้อมูลงวดให้บัญชีแล้ว |
| `POST` | `/api/docs/tax/filings/:fid/due` | `{amount}` ยอดตาม QR |

Migration: `20261117_01_accounting_handoff` (`payments.wht_requested_at`, `tax_filings.sent_at`, `due_amount`, `due_set_at`)
