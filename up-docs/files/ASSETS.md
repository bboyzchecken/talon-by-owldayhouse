# ASSETS.md — ไฟล์ที่ต้องเตรียมก่อนสร้าง

## 1. ฟอนต์ TH Sarabun ๙ (จำเป็น — โจทย์ข้อ 5)

- ต้นฉบับ .docx ใช้ **"TH SarabunPSK"** — มหาลัยประกาศใช้ **"TH Sarabun ๙"** (เวอร์ชันปรับปรุง 2564 ของสำนักนายกฯ) สำหรับหนังสือราชการภายนอก
- **ต้องฝังในไฟล์ HTML** ผ่าน `@font-face` (แปลงเป็น .woff2 หรือ base64) เพื่อให้ PDF ตรงทุกเครื่อง แม้เครื่องที่พรีเซนต์ไม่มีฟอนต์
- ฟอนต์นี้เป็นฟอนต์ราชการแจกฟรี → ฝัง/แจกจ่ายได้ถูกลิขสิทธิ์
- ⚠️ **ห้ามใช้ "Sarabun" ของ Google Fonts แทน** — เป็นคนละฟอนต์ (Google commission) หน้าตาต่าง ไม่ตรงระเบียบ
- fallback stack: `'TH Sarabun New','TH SarabunPSK','Sarabun',sans-serif`

**ต้องขอ/หา:** ไฟล์ `.ttf` ของ TH Sarabun ๙ (2564) ที่มหาลัยใช้จริง — ถ้าไม่ได้ ใช้ TH Sarabun New (ตัวก่อนหน้า) ไปก่อนแล้วสลับทีหลัง
วาง: `up-docs/assets/fonts/` แล้ว gen `@font-face` (regular + bold ถ้ามี)

## 2. โลโก้/ตราหัวเอกสาร

- หนังสือราชการมหาลัยขึ้นต้นด้วย **ตรามหาวิทยาลัยพะเยา** (ในภาพเป็นตราสีม่วง/ทอง) เหนือบล็อกที่อยู่
- ต้นฉบับ .docx ที่แกะเป็น text ไม่มีไฟล์โลโก้ฝัง — **ต้องขอไฟล์ตรา ม.พะเยา** (SVG/PNG พื้นโปร่ง ความละเอียดสูง)
- ถาม DECISIONS: วางตรงไหน (กึ่งกลางบน / เหนือหัว)
วาง: `up-docs/assets/logo/`

## 3. .docx ต้นฉบับ (ground truth)
