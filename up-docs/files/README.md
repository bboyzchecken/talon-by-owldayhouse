# UP Docs — ชุดส่งมอบสำหรับ Claude Code

เครื่องมือออกเอกสารราชการฝึกงาน **คณะบริหารธุรกิจและนิเทศศาสตร์ มหาวิทยาลัยพะเยา**
(demo ฟรีของ Owl Day House เพื่อเสนอมหาลัย → บันไดสู่ระบบเต็ม)

## วิธีใช้
1. วางทั้งโฟลเดอร์ `up-docs/` ลงในโปรเจกต์ **talon-by-owldayhouse**
2. เปิด Claude Code แล้วสั่งประมาณ: *"อ่าน up-docs/CLAUDE.md แล้วสร้างเครื่องมือตามสเปก เริ่มจากใบขอความอนุเคราะห์ + ใบตอบรับ"*
3. Claude Code จะอ่าน `CLAUDE.md` เป็นจุดตั้งต้น และ **หยุดถามตาม `DECISIONS.md`** ก่อนตัดสินใจส่วนที่รอข้อมูล

## ไฟล์ในชุด
| ไฟล์ | คือ |
|---|---|
| `CLAUDE.md` | **อ่านก่อน** — brief: สถาปัตยกรรม, ขอบเขต, UX, DoD, จุดต้องถาม |
| `SPEC.md` | รายละเอียดเชิงลึก: data model, ฟิลด์ต่อใบ, จัดหน้าเป๊ะ, เลขไทย, เทสต์ |
| `templates.json` | **เนื้อความจริงทั้ง 6 ใบ** แปลงเป็น {{token}} + โหมด + โครง 1/หลายคน |
| `reference.json` | ค่ากลาง: ฟอนต์/margin/ผู้ลงนาม/สาขา/พจนานุกรม token |
| `DECISIONS.md` | **จุดที่ต้องหยุดถามเจ้าของ** ก่อนตัดสินใจ/ที่รอข้อมูล |
| `ASSETS.md` | ไฟล์ต้องเตรียม: ฟอนต์ TH Sarabun ๙, ตรา ม.พะเยา |
| `reference-docx/` | **.docx ต้นฉบับจริง 14 ไฟล์** (ground truth — เปิดเทียบตา ห้ามลบ) |

## สรุปที่ตัดสินแล้ว
- HTML ไฟล์เดียว client-side · print-to-PDF · ฝังฟอนต์ · **กระดาษ Letter** · โฮสต์ owldayhouse.com/up-docs/
- 6 ตระกูลเอกสาร · 3 โหมด (สหกิจ=CWIE ต่างแค่วลี) · โครงสลับ 1 คน/2–4 คน · ใบขอพิมพ์พร้อมใบตอบรับ

## รอเจ้าของก่อนสร้างเสร็จ (ดู DECISIONS.md)
Letter/A4 · ขอบเขต 6 ใบ · ยืนยัน print-PDF · **ผู้ลงนาม 5 คน** · **8 สาขา** · นโยบาย typo · ไฟล์ฟอนต์+ตรา
