## 0. บริบท 30 วินาที

Owl Day House (ODH) ทำเครื่องมือออกเอกสาร (`owl-docs-generator.html`) ให้ตัวเองใช้ แล้วเอาไปโชว์ **มหาวิทยาลัยพะเยา (คณะบริหารธุรกิจและนิเทศศาสตร์)** — ลูกค้าชอบ อยากได้บ้าง แต่เป็น **เอกสารราชการ** จึงมีระเบียบเยอะกว่า

**สิ่งที่กำลังสร้าง = DEMO ฟรี** วางบน `owldayhouse.com/up-docs/` ให้เจ้าหน้าที่คณะใช้ **เป้าหมายเดียว: ให้เขาติดใจจนอยากซื้อระบบเต็ม** (ขั้นบันได Custom 15k → ระบบองค์กร 200k+ พร้อมค่าดูแลรายปี) → demo ต้อง **หน้าตาเป๊ะเหมือนต้นฉบับ + ใช้ง่ายสุด ๆ**

**ผู้ใช้จริง = เจ้าหน้าที่คณะ** (ไม่ใช่ dev) เปิด URL → กรอก → พิมพ์ จบ

## 1. สถาปัตยกรรม (ตัดสินแล้ว — อย่าเปลี่ยนโดยไม่ถาม)

| เรื่อง | เลือก | เหตุผล |
|---|---|---|
| รูปแบบ | **HTML ไฟล์เดียว client-side** (แพตเทิร์นเดียวกับ `owl-docs-generator.html`) | ตัวที่ลูกค้าชอบเป็นแบบนี้ · ต้นทุน ~0 |
| เอาต์พุต | **print-to-PDF** (`window.print()`) | คุม 1 หน้าเป๊ะง่ายสุด · ไม่ต้องมี server |
| โฮสต์ | static บน owldayhouse.com/up-docs/ | ไฟล์เดียว โยนขึ้นจบ |
| ฟอนต์ | **ฝัง TH Sarabun ๙** ผ่าน `@font-face` (base64/woff2) | PDF ตรงทุกเครื่อง (ดู ASSETS.md) |
| กระดาษ | **Letter** (ไม่ใช่ A4!) | ต้นฉบับจริงเป็น Letter |
| ข้อมูล | JS object ฝังใน HTML (gen จาก `templates.json` + `reference.json`) | ไฟล์เดียว แต่ maintainจากสเปกได้ |

**.docx (แก้ไขได้) = ฟีเจอร์ของ "ระบบเต็ม" ที่ขายทีหลัง ไม่ใช่ demo นี้** — อย่าเผลอทำ

**ห้าม:** backend, DB, login, framework หนัก, `localStorage`/`sessionStorage` (บน artifact preview พัง — ถ้าจะใช้ให้ทำแบบ optional เปิดเฉพาะไฟล์ที่ deploy จริง), external runtime deps (ยกเว้นฟอนต์ที่ฝัง)

## 2. ขอบเขต — เอกสาร 6 ตระกูล (แกะจากต้นฉบับจริงครบแล้ว)

ดูเนื้อความเต็ม + token + โครงใน **`templates.json`**

1. **ขอความอนุเคราะห์** — 3 โหมด ฝึกงาน/สหกิจ/CWIE · โครง 1 คน (inline) และ 2–4 คน (ลิสต์เลขไทย) · **พิมพ์พร้อมใบตอบรับ**
2. **ใบตอบรับ (เอกสารแนบ)** — 2 โหมด · หน้าถัดจากใบขอ · ดึงชื่อนิสิต/สาขา/วันที่จากใบขออัตโนมัติ
3. **หนังสือส่งตัว** — 3 โหมด
4. **หนังสือขอบคุณ** — ใบเดียวคำรวม "ฝึกงาน/ปฏิบัติสหกิจศึกษา" · โครง 1 คน / หลายคน
5. **นอกหลักสูตร** (ระหว่างปิดภาคเรียน) — A4, 1 คน, มีชั้นปี
6. **ยกเลิกการฝึกงาน** — อ้างเลขหนังสือเดิม

> ข้อ 5–6 พบเกินบรีฟเดิมในโฟลเดอร์ — ยืนยันขอบเขตกับเจ้าของก่อน (DECISIONS.md ข้อ 2)

## 3. UX flow (ให้เจ้าหน้าที่ใช้ง่ายสุด — แก้โจทย์ข้อ 3)

```
หน้าเลือกเอกสาร: การ์ดใหญ่ชัดเจน (แก้ปัญหาเดิมที่ dropdown สับสน)
[ขอความอนุเคราะห์] [ส่งตัว] [ขอบคุณ] [นอกหลักสูตร] [ยกเลิก]
        ↓ ถ้าใบที่มีโหมด → เลือก [ฝึกงาน][สหกิจ][CWIE]
        ↓
ฟอร์มโชว์เฉพาะฟิลด์ของใบนั้น (ตาม fields[] ในแต่ละ doc) + พรีวิว WYSIWYG สด
        ↓
[🖨 พิมพ์ / บันทึก PDF]
```

หลักกันพลาด: ไม่ต้องล็อกอิน/ติดตั้ง · ค่าเริ่มต้นอัตโนมัติ (เดือน/ปีนี้, ข้อมูลคณะ, ผู้ลงนามพร้อมเลือก) · **พิมพ์เลขอารบิก→แปลงเลขไทยอัตโนมัติ** · **กรอกฟิลด์ร่วมครั้งเดียว→เติมทุกจุด/ทุกหน้า** · จำนวนแนบ = จำนวนนิสิต auto · พรีวิวสด · ปุ่มเดียวจบ

## 4. กฎการจัดหน้า (ต้องเป๊ะ — ดูค่าเต็มใน reference.json + SPEC.md)

- ฟอนต์ **TH Sarabun ๙ 16pt**, line-spacing **1.0**
- Margin จดหมาย **ซ้าย 3 / ขวา 2 / บน 1.5 / ล่าง 1 ซม.** · ใบตอบรับแคบกว่า
- ย่อหน้าเนื้อความ **Thai justify** เยื้องบรรทัดแรก ~2 tab (2.54 ซม.) เว้นก่อนย่อหน้า 6pt
- ลิสต์นิสิต ๑. ๒. เยื้องซ้าย 1.27 ซม.
- **เลขไทย + พ.ศ.** ทุกที่ · วันที่ default = เดือน+ปี
- หัวจดหมาย: ซ้าย "ที่ อว ๗๓๒๕/__" · ขวา 3 บรรทัดที่อยู่ ม.พะเยา · วันที่กึ่งกลาง
- บล็อกผู้ลงนามเหมือนกันทุกใบ

## 5. โจทย์ 8 ข้อ → แก้ตรงไหน (ทวนให้ครบ)

1. 3 โหมด → `templates.json` modeText (สหกิจ/CWIE ต่างแค่วลี)
2. เอกสารแนบพิมพ์พร้อมกัน → doc `acceptance` เป็นหน้าถัดไป + ดึงชื่อนิสิต auto
3. แยกใบชัด → การ์ดเลือกใบ (ข้อ 3 ด้านบน)
4. ใบขอบคุณ → doc `thanks`
5. ฟอนต์ Sarabun ๙ → ฝัง @font-face (ASSETS.md)
6. นิสิต 1–4 คน 1 หน้า → โครง single/many + auto-fit (ข้อ 6 ด้านล่าง)
7. margin ต้นฉบับ → ค่าใน reference.json (วัดจริงจาก .docx แล้ว)
8. เลือกผู้ลงนาม 6 คน → dropdown จาก reference.signers (รอ 5 คน)

## 6. รับประกัน "1 หน้า" (โจทย์ข้อ 6 — สำคัญ)

- กระดาษ Letter คงที่ + โครง `single` (1 คน inline) / `many` (2–4 คน ลิสต์)
- หลังเรนเดอร์ วัด `scrollHeight` เทียบความสูงหน้า → ถ้าเกิน ค่อย ๆ ลด line-height/ขนาดทีละ step ในกรอบระเบียบ + เตือนบนจอ (ไม่โชว์บน PDF)
- **ใบตอบรับเป็นคนละหน้าโดยตั้งใจ** (page-break) → ไม่แย่งที่กับจดหมาย รวมใบขอ+แนบ = 2 หน้า/1 งานพิมพ์
- ทดสอบครบ 1/2/3/4 คน × ทุกโหมด × org ชื่อยาว

## 7. หยุดถามก่อนตัดสินใจ (ทำตามคำสั่งเจ้าของ)

อ่าน **`DECISIONS.md`** — ทุกจุดที่ยังไม่มีข้อมูล/มีทางเลือก **ให้ถามเจ้าของก่อน อย่าเดา** โดยเฉพาะ:
- Letter vs A4 (ตัวนอกหลักสูตร) · ขอบเขต 6 ใบ · ยืนยัน print-PDF
- **ชื่อ+ตำแหน่งผู้ลงนามอีก 5 คน** · **รายชื่อ 8 สาขา** · หลักสูตรอื่น
- นโยบาย typo ต้นฉบับ (ด้วยด้วย / สถานประกอบการณ์ / ไม่ทราบ→ไม่สามารถ)
- การส่งตัว/นอกหลักสูตร/ยกเลิก แบบหลายคน (ต้นฉบับมีแค่ 1 คน)

ที่ที่ต้องรอข้อมูล ให้ทำ placeholder ชัด (`__รอข้อมูล__`) + คอมเมนต์ TODO ไว้ อย่าแต่งข้อมูลเอง

## 8. Definition of Done

- [ ] เลือกได้ครบ 6 ใบ (+โหมด) จากการ์ด
- [ ] ฟอนต์ Sarabun ๙ ฝังในไฟล์ เรนเดอร์ตรงแม้เครื่องไม่มีฟอนต์
- [ ] Letter + margin ตรง reference.json · เทียบ .docx ต้นฉบับใน `reference-docx/` แล้วตา
- [ ] เลขไทย/พ.ศ. อัตโนมัติ · จำนวนแนบ = จำนวนนิสิต
- [ ] กรอกครั้งเดียวเติมทุกจุด+ใบตอบรับ
- [ ] ใบขอ + ใบตอบรับ พิมพ์ครั้งเดียวได้ 2 หน้า
- [ ] นิสิต 1/2/3/4 คน จดหมายอยู่ 1 หน้าเสมอ
- [ ] เลือกผู้ลงนามได้ · บล็อก "ปฏิบัติการแทน" ถูกตามคน
- [ ] พรีวิวสด + ปุ่มพิมพ์ทำงาน · ไม่มี dependency นอกไฟล์
- [ ] คอมเมนต์โค้ดภาษาไทยได้ อ่านง่าย แก้ต่อง่าย
